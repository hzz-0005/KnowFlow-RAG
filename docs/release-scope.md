# v0.1.0 首版范围

这是本地运行的研究/开发原型，首次源代码发布不等于六条研发主线全部语义验收通过。

| 主线 | 首版边界 | 后续 |
|---|---|---|
| 多轮与记忆 | 持久会话、有限指代与候选发现、任务/显式记忆首版；每轮重新检索 | 复杂歧义、冲突、长期连续性独立评测 |
| 评测 | 可运行离线工具、合成反例、unknown/适用性/执行分账 | M1外审、代表性金标与首次独立质量基线 |
| 检索与回答 | 关键词/向量混合、可选重排、引用与拒答、诊断 | 同预算质量对照及收益验证 |
| 文档 | PDF/DOCX/MD/TXT/CSV/XLSX、可选本地Docling、来源/切片/报告/批任务 | 跨页续表、复杂阅读顺序、自动坏页恢复 |
| 图增强 | 有来源实体/关系、构图及图检索实验入口 | 关系语义、覆盖、多跳收益与消融 |
| 跨文件 | 同知识库多文档检索与分别引用 | 对象身份、版本有效期、冲突裁决及确定性计算 |

不承诺任意PDF都解析正确、任何追问都能消歧或任何文档都完整入图。报纸跨版面标题尚可能被拆为不同章节；没有字段说明的数字不能猜成学号。总结的citation_checked只检查引用标记，不能当逐句语义复核。长期记忆不是文档事实。

多文档候选按文件分配预算，并披露取回、上下文、引用及未检查范围；这仍是有界片段检索。开发观察中，双文件可以均有候选却仍未取回指定数值，不能用“引用了两份”冒充完整回答。尚未覆盖全文的检索结果不支持“原文没有”或“全库唯一”的断言。

工程检查、干净安装、真实API开发观察、独立语义标签分别记录；没有独立标签，不公布泛化准确率或图增强收益。公开包不分发真实金融年报、论文PDF、原用户上传及历史聊天；合成控制不是保留集。
