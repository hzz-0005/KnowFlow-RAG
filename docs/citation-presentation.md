# 引用节选与补充原文

回答详情中的引用卡片先显示`quote`：保留当时相关性阶段验证、保存的节选与原定位。为便于自主核对，`context_excerpt`可提供同一切片的额外窗口，放在默认折叠的“更多原文上下文”中；它不替换quote，也不表示窗口中的每句都被审核支持。

上下文不足整块40%时，可提供最多1200字符的同切片窗口；能定位原句时围绕原句取窗，不能定位则保持原节选。原节选本身不因扩展窗口上限被删除。多处分散引文、跨切片断言或模型错误归因仍须单独复核，不能用长度比例证明支持度。

最终回答的多来源列表先拆为单项标记，再通过已提供上下文ID白名单校验并编号；未知或损坏来源拒绝。不能靠删除裸ID来遮盖未通过校验的来源。普通数字数组、浮点列表等正文数据不改写。

这些是展示/引用格式保护，不是新的语义质量指标。旧持久结果仍展示其原字段，不用当前文档替旧回答重做引用；新可选上下文字段只由新查询保存。本轮实现/反例/真实页面见接回审核（本地研究记录，未随公开包分发）。
