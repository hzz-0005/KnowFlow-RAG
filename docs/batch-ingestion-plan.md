# 批量文档自动解析与分块：调研后的改造方案

日期：2026-10-22。状态：结构/token 分块与解析缓存已实现；完整持久批量流水线尚未实现。

2026-10-23 更新：持久批任务首版已落地，当前实现与限制见 [持久摄入说明](durable-ingestion.md)。下文保留为 2026-10-22 的调研与设计背景，其中“尚未实现”不再作为当前功能清单。

## 目标与研发验收的区别

批量导入不应要求操作者逐份查看切片、批准 OCR 候选或手工调整边界。研发时人工检查原页用于建立标注、发现通用缺陷，不属于每份文档的运行依赖。原页预览和切片检查器保留为可选诊断工具。

上一轮表注修复是运行于所有文档的通用规则，不是保存某文件专属的块位置映射；但是一个真实文件及少量合成例子不足以证明泛化。当前没有完整的自动质量路由和持久导入队列，不能称为无人值守批量闭环。

## 改造前的实现审查

- `chunk_parsed_document` 的打包键仍包含物理页、章节字符串和解析父块 ID。物理页变化就不能合并，跨页语义连续性未作为一等结构处理。
- 长度主要受 `CHUNK_CHARS=1000` 和字符重叠控制，没有按实际 embedding tokenizer 的完整输入预算管理。
- 已保存来源块、位置、表格行和明确编号引用，但没有独立的父章节内容存储与子块到父块的完整检索机制。
- 表注几何关联仅覆盖有限条件，不能承担所有续表、错标题和图内文字的修复。
- 解析报告和单页 OCR 对照主要服务人工诊断；异常信号尚未驱动有限重试、备选解析器与自动隔离。
- 文档处理由 API 后台任务触发，缺少覆盖整个导入流程的持久状态、崩溃恢复和阶段缓存。

## 本轮落地范围

- 默认 `structure_tokens`：同章节/父块/类型范围内按完整输入 token 预算打包，物理换页不强制断块。超长元素按段落、行、句子细分；正文分片重叠，表格保留行与表头，超长单行保留并提示。
- 默认预算 512、目标 384、预留 16、正文重叠 48；章节和表注上下文一起计数。离线 Qwen3 tokenizer 有固定版本和校验和，但未证明与托管 Qwen3.7 完全一致，界面明确显示为估算。
- 自动检查输入单元的非空白字符覆盖和每块完整输入预算。失败时不替换旧索引；这不是语义正确率或 OCR 准确率。
- 每块记录类型、估算 token、来源页和分片状态。跨页块保留独立来源范围；经验证引文可定位相应来源页，旧块仍使用较粗来源。
- 解析后的规范化块、章节和报告保存为带校验和的 gzip 产物。`重新分块` 不重新 OCR；原文件、解析器版本/端点或页数配置变化会使缓存失效。更换解析器模型需主动更新 `PARSE_ARTIFACT_REVISION`。不是完整原始 Docling 响应归档。
- 保留 `legacy` 字符策略用于对照。新策略不会自动重建用户现有文档。

尚未落地：持久作业队列、重启自动续作、备选解析器质量路由、自动有限重试与隔离队列、通用续表合并和完整父子块检索。报告中的 `needs_review` 是可选诊断，当前没有逐文件人工批准关卡。

## 自动流水线

1. **预检与路由**：根据文件格式、文字层、页面图像和结构复杂度选择原生解析或版面/OCR。扫描与混合文件按页处理，保留文档级组织。
2. **保留原始转换产物**：保存解析器与模型版本、参数、原始页级输出及规范化块，不只保存扁平 Markdown。后续重新分块不必重跑 OCR。
3. **恢复文档结构**：先处理阅读顺序、标题树、跨页续段和续表、表注、脚注、图内示例角色，再产生检索块。每次合并记录证据和所有来源位置；冲突保持未消解。
4. **结构与 token 联合分块**：正文按章节/段落/句子；表格按表头与完整行组；代码和公式独立；图片文字与图注保留角色。超长才进一步拆，小块在结构兼容时合并。tokenizer 优先与 embedding 模型一致，若无法取得对应版本则明确标记估算器和安全余量，不能声称精确一致。
5. **父子证据索引**：子块用于精确召回，父章节/完整表格独立保存。按问题补回必要原始上下文并受总预算约束；摘要只能做检索辅助，不能替代原始证据。
6. **自动质量路由**：正常结果直接入库；异常页/区自动重试；仍失败的部分自动隔离并报告范围，其他文档继续。用户不需要逐份审批。

不以“每个句子都做 embedding”“每页都调用大模型重写”作为默认路径。对于无可靠结构的长段落，先用句子/递归切分与 token 限制；语义相似度分段作为对照选项，需评测其收益与计算成本。

## 质量路由的边界

可观察信号包括原页数与来源页、空页异常、替换字符、阅读顺序、重复内容、碎片化标题、来源字符范围覆盖、表头和单元格结构、孤立表注及未解析引用。各信号不是原文真值：文字更多可能来自图内示例，OCR 乱码更少可能同时漏掉正文，标题识别与逐字引文存在也不证明语义正确。

需要将各指标与人工建立的留出集比较后定阈值，不直接采用任意“字符保留 90% 就通过”的结论。解析器分数缺失时记未知，不用 LLM 自报置信度补成概率。

自动重试顺序可比较：调整 OCR/版面参数 → 对异常页连同必要邻页做备选解析 → 对结构歧义做受约束的视觉/结构恢复。候选只有通过同一套来源、覆盖、结构与不丢数值检查后才自动采用；其他情况隔离，不无限重试，不仅按字符更多择优。所有重试有页数、耗时、模型调用和费用预算。

被隔离的页仍保留原件和诊断，不静默删除；查询层明确资料存在未解析部分，不把检索不到当作原文没有。是否允许其余已验证页面部分入库须有显式产品状态和检索过滤，不能复用当前 processed 状态掩盖缺页。

## 批处理的运行要求

- 持久作业按解析、结构恢复、分块、embedding、图索引分阶段保存状态；使用租约、心跳、有限重试与死信状态。
- 文件哈希 + 解析/模型/分块配置版本构成缓存依据；重试幂等。只重算失效阶段，不因分块修改重复 OCR。
- 新版本索引构建、验证完成后原子切换；失败不覆盖旧有效索引。
- 设置解析并发、embedding 并发、队列背压及资源预算；不能将开启无限并发等同批处理优化。
- 按文件和页显示失败原因；少数异常不得阻断整批文档。人工复核为可选诊断，不是默认入库门槛。

## 验收方式与实施顺序

先冻结现有代码及小样本作为基线，再建立文档级留出集，包含中文/英文、扫描/混合、多栏、假标题、跨页段落/表格、错表头和图内示例。新增文档进入评测时不允许再针对其页码/文件名添加特例。

比较当前分块、结构/token 分块、父子上下文、异常恢复四个阶段，分别记录：自动完成率、自动恢复率、隔离率及误放行率，来源/关键数值保持，Recall@K、完整证据集召回和实际回答忠实度，以及吞吐、P95 耗时和模型调用成本。模拟中断后恢复和重复提交，确认无重复索引、无资料静默丢失。

优先实现结构/token 分块接口和可复用原始产物，再加入持久队列与质量路由、父子证据和结构恢复对照。不继续按某个文件切片数减少来衡量成功。
