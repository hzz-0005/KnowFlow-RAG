# 纠错后的回答语言

旧真实开发样本的英文原问题和英文首稿在纠错后变为中文。本包将当前用户原话以服务端显式参数携带到 repair payload；不从用户填写的 JSON 中猜内部字段。明确翻译目标、双语或指定语言优先，否则跟随当前用户自然语言；审核反馈、证据、历史问题、检索线索和系统提示语言不参与选择。

移除了 repair 提示中唯一的中文条件句示例，改用语言中性的条件说明。该示例可能造成偏向，但没有独立实验确认唯一根因。语言是提示约束，没有把语言检测概率当成语义正确证明。

新增载荷参与完整请求预算、请求 SHA256 与评测契约；不截断原问题来凑窗口。仍只纠错一次，候选正常结束且第二次依据复核 `complete` 后才能采用；没有借语言修复绕过引文或事实核验。

复现使用旧保存请求的精确 SHA256 和未变来源，只新跑一次纠错与一次审核；最终为英文且二审完成。不是从头重跑、随机抽样准确率、paired baseline 或提速成绩。原先中文结果保留，详见 复现（本地研究记录，未随公开包分发） 与 协议（本地研究记录，未随公开包分发）。
