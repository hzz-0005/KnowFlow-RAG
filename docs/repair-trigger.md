# 按过滤原因决定是否纠错

触发规则版本为`evidence-driven-repair-v1`，在线块审核版本为`sentence-review-atomic-blocks-v4-filter-reasons`。本包修复“纯引导段被过滤也触发重写”的执行策略，不修改模型、审核提示或[完整请求预算](guard-budget.md)。

## 唯一新增的省略分支

必须同时满足：已有可返回的核验事实正文、状态filtered、首审complete、未知单元为0、所有遗漏块均是普通叙述块，且每个单元都有唯一not_factual判断。遗漏计数必须与总块/保留块一致。满足时返回原有保留正文及已验证的来源绑定，不调用纠错生成和二审；仍保存filtered、被省略原文与原因，不能把原草稿写成全部通过。

普通叙述的语法边界保守排除表格、列表、标题、引文、缩进代码、围栏代码/图、含行内代码或链接等结构块。这不是语义分类器；它只阻止结构化内容误走新的省略分支。是否not_factual仍是模型判断，可能误判，不能保证没有语义损失或回答覆盖完整。

任何unknown、unsupported、contradicted、缺项、重复、无效引文、审核未完成，或结构块被过滤，均不能使用该省略分支。只有引导语、没有可返回事实时，也保留原拒绝/一次来源优先修复路径。没有新增开头关键词、实体、文件名或业务判断。

## 兼容与观察

`reviewed_blocks[].kind/filter_reason`记录语法类别和保留/省略原因；`omission_counts`区分nonfactual_prose与requires_attention。`repair_trigger`记录版本、decision与reason；已采用修复的记录保留首审触发信息，页面从initial_review显示。历史缺字段不推测，原轮次不重新标注。

其余分支保持既有策略：纠错关闭则不调用，审核不可用/超限保持未知，filtered/rejected需要处理时最多一次修复；候选仍须二审complete才采用。二审采用标准、整块保留、引文校验、预算、取消和来源优先提示都未放宽。

现有guard_budget_contract新增repair_trigger_version，新旧合同不可当同策略回归；不改M1冻结账本、保留集或历史报告。没有新增实际.env配置或key。

## 验证边界

本轮复用保存的首审、同一原稿与原合成文档作零模型回放。改前派发纠错1次（被测试桩拦截），改后0次；保留正文SHA相同。这证明该固定输入的本地派发变化，不是远程提速或费用结论。另有多领域控制及保守反例；真实页面只运行一次预先声明的新分支控制，模型若不生成独立引导块也不得反复重问。本轮记录（本地研究记录，未随公开包分发）。
