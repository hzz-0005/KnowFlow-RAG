# 在线整轮执行预算

2026-10-25，`online-round-admission-v1`。单次知识库查询与会话每一轮使用独立账本，会话的上下文解析与后续查询共用；下一轮重新建立额度。重复request_id沿原幂等路径读取已有轮次，不重新请求模型。

范围包括查询改写、embedding每批、可选重排、相关性、首稿、每次依据审核与纠错生成。准入在SDK/HTTP请求前执行。已有分阶段完整输入预算继续生效，不能为凑整轮额度截断原始条件或跳过审核。

| 配置 | 默认 | 含义 |
|---|---:|---|
| QUERY_MAX_PROVIDER_CALLS | 12 | 整轮允许发起的供应商请求数，包含失败/取消 |
| QUERY_TOTAL_RESERVED_TOKENS | 131072 | 累计本地输入估算+输出预留的运行准入额度 |
| QUERY_TIMEOUT_SECONDS | 180 | 沿用整轮异步期限，会话解析与查询之间不重置 |

聊天使用实际messages、角色封装估算及显式输出上限；embedding估完整本批文本+64，重排估问题/所有候选/指令+128。这里的余量是本地估算规则，不能认为与供应商分词或计费单位精确一致。不是模型窗口、实际价格、金额上限或保证永不超出的远端token硬配额。

调用前完整占额度，无await的准入过程避免同轮并发越过本地计数；额度不随低实际用量、失败或取消退还。拿到total_tokens高于该次预留时补计差额；若累计超限，后续请求被阻止，已发生的费用无法撤销。total_tokens缺失时不反推为零：保留provider_usage、已知总token小计、未知调用数，整轮总量为null；真实0与null不同。不同模型token数的求和只是运行量观察，不是费用计算，billing_amount始终null。

在线SDK请求显式max_retries=0；httpx重排未启用自动重试。request数只说明本地发起的供应商API尝试，不保证供应商服务端只处理一次。失败、超时、断连或进程崩溃均可能已计费；客户端取消不能撤销供应商的工作。原离线run_query/评测CLI与批量摄入没有隐式套此在线scope，原重试规则保留；不得把离线基线假称已经受到本配额约束。

Python ContextVar用于请求隔离和嵌套共享；兼容本项目Python3.12容器和本地3.13，使用set/reset/finally，不依赖3.14新语法。asyncio.timeout只约束异步可取消执行，不能中断阻塞同步初始化来保证严格墙钟上限；持久化提交不放进模型调用额度。依据：[Python3.12 contextvars](https://docs.python.org/3.12/library/contextvars.html)、[asyncio超时](https://docs.python.org/3.12/library/asyncio-task.html#timeouts)、[SDK默认重试与配置](https://github.com/openai/openai-python#retries)。

首次准入拒绝后锁住整轮，不再因为后续请求较小而重新派发；记录blocked行但不把它计为实际调用。会话的response与resolution都保存快照，失败/中断即使无答案仍保存resolution.round_budget。单次query接口超时沿用504字符串detail，普通异常仍按原错误合同；这些单次异常没有新增持久账本，完整失败快照只保证在会话流程保存。已返回内容沿原审核/引文保护：审核被阻止则不得直接交付未经核验草稿；纠错或二审被阻止，仍只允许原已核验部分按原策略返回。预算状态不是语义质量状态，收到响应不代表支持判断正确。

详情“整轮执行预算”查看各请求及拒绝阶段；失败聊天气泡显示简要计数。旧轮次无该字段不反推。账本不保存提示内容、供应商异常正文、URL或凭据，只保留阶段/模型/用量白名单/封闭原因等。限额记录未实现跨进程共享配额、用户月费配额、价格表或账单对账；服务器崩溃未落盘的中间状态仍可能丢失，需要后续持久调用账本补齐。

工程与实际页面证据见本包记录（本地研究记录，未随公开包分发）。后续仍需复杂问题拆解、任务状态、长期记忆和独立多轮语义基线，M1–M7总体路线保留。
