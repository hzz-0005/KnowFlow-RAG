# 首版之后的开发队列

v0.1.0以安装/运行/测试/来源可检查为界，不等待解决任意复杂场景，也不把发布当语义验收通过。

1. v0.1.x：安装、配置、异常恢复、文档和真实反馈修复；已完成前端由用户验收，不反复测旧问题。
2. 评测基础：账本外审、代表性真实题/来源标注、开发与保留集、固定预算基线；unknown不计0，同文档多题考虑相关性。
3. 检索/多轮：口语错字、指代和候选确认、条件更正/话题边界、有限多步查询、同池有无重排对照；任务与记忆隔离/冲突。
4. 文档：优先常见表头、章节、扫描缺失、跨页续表和阅读顺序；特殊报纸跨版面标题作压力场景。原文/附属上下文/模型候选分开保存；字段含义必须有出处。
5. 图增强：关系方向/作用域/来源、多跳链、同预算文本扩展消融；无收益时保留负结果或关闭。
6. 跨文件与规模：身份、版本/生效期、更正、来源优先级及确定性计算；根据实际规模再扩存储与队列。

首版上传GitHub后另做本地工程瘦身，确认无依赖的旧产物进入to-delete隔离目录；有效回归、当前数据、迁移和锁文件不能误删。内部历史材料不随公开源码分发。
